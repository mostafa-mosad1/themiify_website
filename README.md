# Dashboard & Admin Panel – Themes Platform

## 📌 Project Overview

This project is a **Dashboard & Admin Panel system** built to manage and showcase the company’s themes in a professional and organized way.

The main idea of the project is to:
- Display all company themes in a clear and structured interface.
- Provide detailed information about each theme.
- Allow full customization and management of themes through an Admin Panel.
- Separate the client-facing interface from the admin management system.

The project is designed to be scalable, maintainable, and easy to extend in the future.

---

## 🎯 Project Purpose

- Centralize all company themes in one dashboard.
- Give admins full control over:
  - Adding new themes
  - Editing theme details
  - Managing theme customization options
  - Managing users (if needed)
- Provide a clean client interface to:
  - Browse available themes
  - View full descriptions and features
  - Understand how each theme can be customized

---

## 🧩 Project Structure

The project is divided into two main parts:

### 1️⃣ Client Interface
- Displays all available themes.
- Shows detailed information for each theme.
- Explains theme features, use cases, and customization options.
- Focused on presentation and user experience.

### 2️⃣ Admin Panel
- Protected area for admins only.
- Dashboard with overview and statistics.
- Full CRUD operations for themes.
- Ability to edit theme content, descriptions, and settings.
- User management (optional / extendable).

---

## 🛠 Tech Stack

This project is built using modern and reliable technologies:

- **Next.js** – React framework for routing, performance, and scalability
- **TypeScript** – Strong typing for safer and more maintainable code
- **Tailwind CSS** – Utility-first styling for fast and responsive UI
- **React Icons** – Icon library used across the dashboard and UI
- **Sonner** – Toast notifications for alerts and user feedback
